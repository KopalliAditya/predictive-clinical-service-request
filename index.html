Set Up Patient Access Scoring for Clinical Service Requests

Predict which referrals are most likely to be accepted, and write that score back onto the Clinical Service Request so referral coordinators can prioritize their queue — set up end to end in three steps.

Patient Access Scoring uses the Data Cloud Scoring Framework to train a predictive model on your historical Clinical Service Requests (CSRs). The model produces a score for each new request, and that score is written back to the Referral Score field on the Clinical Service Request record in your CRM.

Referral scores are not clinical quality scores Referral scores are based on time in the queue and listed clinical urgency — not on ingested clinical data. Do not use predictive scoring to triage emergency cases.

How it works

Your CSR data flows from the CRM into Data Cloud, where a model scores it and the score is copied back to the CRM:

  • Data kit — maps your CSR objects into the Data Cloud model objects (DMOs) the model reads.
  • Scoring template — installs the model definition, chooses the features, and defines the training label (referral acceptance).
  • Copy Field Enrichment (CFE) — writes the model's score from Data Cloud back onto the Clinical Service Request record.

Set up in three steps

Step 1

Install the Data Kit

Deploy the Health Cloud Scoring data kit so your CSR data maps into the DMOs the model reads.

 Step 2

Install the Scoring Template

Install the Patient Access Scoring template in the Scoring Framework and choose each parameter.

 Step 3

Enable the Score Writeback

Grant the Copy Field Enrichment integration user the right permissions so the score lands on the CSR.
Before you start Review the Prerequisites first. The most common setup failures come from Data Cloud not being provisioned, the CSR DMO being empty, or the integration-user permissions in Step 3 being skipped.

What makes this guide different from the standard doc

The official Set Up Referral Management Predictive Scoring article covers the happy path in a few sentences. This guide adds the detail customers actually need to finish the setup:

  • What each Scoring Framework template parameter does and how to set it — not just "install the template."
  • The exact integration-user permissions the writeback needs, which are easy to miss and cause scores to silently never appear.
  • A troubleshooting section for the two failures that block most first installs: the model stuck in Activating, and a missing Referral Score field.
