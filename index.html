Set Up Predictive Analytics for Clinical Service Requests

Install the data kit, install the scoring template, and enable the score writeback so a predictive score is written back to each Clinical Service Request.

This feature uses the Data Cloud Scoring Framework to train a model on your Clinical Service Requests (CSRs). The model scores each request, and the score is written back to the Referral Score field on the Clinical Service Request in your CRM.

Required Editions

Available in:
Lightning Experience
Enterprise, Performance, and Unlimited editions with Health Cloud
Requires:
Data Cloud provisioned with an active data space
Referral scores are not clinical quality scores Referral scores are based on time in the queue and listed clinical urgency — not on ingested clinical data. Do not use predictive scoring to triage emergency cases.

How it works

Your CSR data flows from the CRM into Data Cloud, where a model scores it and the score is copied back to the CRM:

CRM
Clinical Service Request
→
Data Cloud
Data Stream → DLO → DMO
→
Scoring Framework
Model trains & scores
→
Scoring DMO
Derived Score
→
CRM
Referral Score field
  • Data kit — maps your CSR objects into the Data Cloud model objects (DMOs) the model reads.
  • Scoring template — installs the two Batch Data Transforms (BDTs) and the Einstein Studio AI model, chooses the features, and defines the training label (referral acceptance).
  • Copy Field Enrichment (CFE) — writes the model's score from Data Cloud back onto the Clinical Service Request record.

For a closer look at the data transforms and the AI model, see How It Works.

Set up in three steps

Step 1

Install the Data Kit

Deploy the Health Cloud Scoring data kit so your CSR data maps into the DMOs the model reads.

 Step 2

Install the Scoring Template

Install the Predictive Analytics for Clinical Service Requests template in the Scoring Framework and choose each parameter.

 Step 3

Enable the Score Writeback

Grant the Copy Field Enrichment integration user the right permissions so the score lands on the CSR.
