Prerequisites

Confirm these are in place before you begin.

Org and licensing

  • Health Cloud enabled (Enterprise, Performance, or Unlimited edition, Lightning Experience).
  • Data Cloud provisioned, with at least one active data space. You select this data space in Steps 1 and 2.
  • Clinical Service Request records exist in your CRM. The model trains on these records (see Data readiness below).

Data readiness

The scoring template runs readiness checks when you install it. Meet these so the checks pass:

RequirementDetail
The ClinicalServiceRequest DMO is mapped The readiness check requires Id, ClinicalServiceRequestPriority, and ClinicalServiceRequestStartDate to be present.
At least 400 Clinical Service Request records Fewer than 400 records fails the readiness check.
A mix of accepted and not-accepted requests The model predicts acceptance and needs both outcomes to train. If all requests have the same outcome, training can produce a single-class model. This check warns but does not block install.
What "accepted" means A request counts as accepted when IsAccepted is true, or when the request Status is Active or Completed. This is how the default training label is defined.

Permissions
